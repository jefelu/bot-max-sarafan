# Сарафан — бот объявлений района Солнечный (MAX)

Публичный репозиторий для бота «Сарафан» на платформе JetBot и мессенджере MAX.
Канал объявлений ведёт ИП Понкрашкина Е. В.

## Статус

- Бот создан на JetBot (сценарий собран в редакторе, 66 блоков).
- Сценарий **не протестирован** по чек-листу из руководства.
- Публикация в канал через API MAX **не проверена**.

## Что нужно исправить до запуска

1. Убрать выдачу прав админа первому пользователю, если `admin_id` пуст.
2. Убрать проверку админа по отображаемому имени: его легко подделать.
3. Убрать ID админа из кода. Задавать его глобальной переменной `admin_id` вручную.
4. Токен бота MAX хранить в настройках интеграции JetBot или в переменных окружения. В репозиторий и в чат его не класть.
5. Проверить, что JS-блок JetBot видит загруженные фото. Если не видит, фото остаются в истории чата.
6. Проверить публикацию в канал через `POST /messages` с `chat_id` канала. Бот должен быть администратором канала с правом публикации.

## Чек-лист тестов

- [ ] Новый пользователь подаёт объявление в тему T1, проходит анкету до предпросмотра.
- [ ] Тот же пользователь подаёт повторно в T1 в течение 72 часов — видит окно и время открытия.
- [ ] Подача в T2 не зависит от T1.
- [ ] Отказ и доработка не сдвигают окно 72 часа.
- [ ] Пакет «Неделя» на T1 разрешает подачу сразу; T2 не затрагивается.
- [ ] Текст со стоп-словом (например, «криптовалюта») отклоняется с кодом R1.
- [ ] Текст длиннее 800 символов отклоняется.
- [ ] Пользователь, не являющийся админом, не открывает панель администратора.
- [ ] Дубликат текста с другого аккаунта даёт флаг в карточке админа.
- [ ] Публикация в канал через API создаёт пост и записывает дату публикации один раз.

## Секреты

Никаких токенов, паролей и реквизитов в репозитории. Имена переменных можно указывать: `MAX_BOT_TOKEN`, `CHANNEL_CHAT_ID`, `admin_id`.
